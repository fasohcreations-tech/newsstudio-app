# Module 3.4 – GNN Broadcast Package v1

GNN Broadcast Package v1 is the default, editable Scene Composer package for Good News Flash.

It ships as JSON-first scene/component defaults (no static PNG templates, no rasterized layouts).

## What is seeded

- Master design system (typography, palette, spacing, motion language, visual tokens)
- Component library (background, header, footer, headline, video, image, logo, ticker, clock, date, reporter, quote, verse, statistics, animation)
- Motion preset library (fade/slide/reveal/zoom/push/typewriter/blur/elastic/bounce/mask reveal)
- 10 master scenes:
  - `GNN-001` Standard News Story
  - `GNN-002` Breaking News
  - `GNN-003` Headlines
  - `GNN-004` Live Reporter
  - `GNN-005` Interview
  - `GNN-006` Scripture
  - `GNN-007` Quote Card
  - `GNN-008` Statistics
  - `GNN-009` Timeline
  - `GNN-010` Outro

## Implementation map

```text
src/features/scene-composer/
  constants/gnn-broadcast-package.constants.ts   # design system, component library, scene definitions
  lib/gnn-broadcast-package.ts                    # scene JSON draft builder
  lib/responsive-layout.ts                        # responsive variants for 16:9, 9:16, 1:1, 4K
  services/scene-composer.service.impl.ts         # ensureDefaults seeds package into DB
```

## Variable binding set

All scenes include bindings for:

`{{headline}}`, `{{subheadline}}`, `{{summary}}`, `{{reporter}}`, `{{guest}}`, `{{designation}}`, `{{location}}`, `{{date}}`, `{{time}}`, `{{logo}}`, `{{image}}`, `{{video}}`, `{{voice}}`, `{{music}}`, `{{ticker}}`, `{{quote}}`, `{{author}}`, `{{verse}}`, `{{reference}}`

## Responsive engine

`buildAllResponsiveVariants()` generates editable layout variants for:

- `1920x1080`
- `1080x1920`
- `1080x1080`
- `3840x2160`

Variants are stored in scene `properties.responsive_documents`.

## AI-ready contract

AI is constrained to placeholders and bindings:

- choose scene
- populate variables
- replace image/video references
- generate copy fields (headline/subheadline/verse/quote)

The structural layout and timeline objects are never regenerated by AI.

## Notes

- Package metadata key: `gnn-broadcast-v1`
- Scenes remain reusable and editable in Scene Composer
- Existing modules are extended, not redesigned
